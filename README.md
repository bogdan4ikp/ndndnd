# ndndnd
      
Built a highly premium, futuristic and gorgeous technology platform landing page called "NDNDND" (The Next-Gen Decentralized Neural Dimension). It features stunning glowing CSS designs, a dynamic built-in language translator supporting English, Russian, and Spanish, high fidelity multi-step registration modal with username and password security validator, dynamic telemetry audio-like bars, and an interactive private neural console dashboard after successfully completing the registration process.

## Запуск проекта локально
1. Установите зависимости: `npm install`
2. Запустите в режиме разработки: `npm run dev`
3. Откройте локальный адрес в браузере.
